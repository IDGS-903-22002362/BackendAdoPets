# Solución al Error de Transacciones con SqlServerRetryingExecutionStrategy

## ?? Error Original

```
The configured execution strategy 'SqlServerRetryingExecutionStrategy' does not support user-initiated transactions. 
Use the execution strategy returned by 'DbContext.Database.CreateExecutionStrategy()' to execute all the operations 
in the transaction as a retriable unit.
```

## ?? Causa del Problema

SQL Server tiene una **estrategia de reintento** configurada (`SqlServerRetryingExecutionStrategy`) que automáticamente reintenta operaciones fallidas. Sin embargo, **no es compatible** con transacciones manuales iniciadas con `BeginTransactionAsync()`.

### **Código Problemático (Antes)**

```csharp
public async Task<TicketDto> CreateTicketAsync(CreateTicketDto dto, Guid createdBy)
{
    // ? PROBLEMA: Transacción manual con estrategia de reintentos
    await using var transaction = await _context.Database.BeginTransactionAsync();

    try
    {
        // ... operaciones
        await transaction.CommitAsync();
    }
    catch
    {
        await transaction.RollbackAsync();
        throw;
    }
}
```

## ? Solución Implementada

Usar `CreateExecutionStrategy()` para envolver toda la transacción:

```csharp
public async Task<TicketDto> CreateTicketAsync(CreateTicketDto dto, Guid createdBy)
{
    // ? SOLUCIÓN: Crear estrategia de ejecución
    var strategy = _context.Database.CreateExecutionStrategy();

    // ? Ejecutar toda la transacción dentro de la estrategia
    return await strategy.ExecuteAsync(async () =>
    {
        await using var transaction = await _context.Database.BeginTransactionAsync();

        try
        {
            // ... operaciones del ticket

        {
            await transaction.RollbackAsync();
            throw;
        }
    });
}
```

## ?? ¿Qué Hace `CreateExecutionStrategy()`?

1. **Crea una estrategia de ejecución** compatible con transacciones manuales
2. **Envuelve toda la operación** en un bloque reiniciable
3. **Permite reintentos** si hay fallos transitorios de conexión
4. **Mantiene la integridad** de la transacción completa
