# Implementación de Precio Unitario en Endpoint de Inventario

## ?? Descripción

Se agregó el campo `PrecioUnitario` al endpoint `GET /api/v1/items/inventario` **sin modificar la base de datos**. El precio se calcula dividiendo el precio del lote (presentación completa) entre la cantidad de unidades por presentación (`MinQty`).

---

## ?? Lógica de Cálculo del Precio

### **Fórmula**

```
Precio Unitario por Unidad = Precio del Lote ÷ MinQty
```

### **Ejemplo Práctico**

```
Item: "Vacuna Antirrábica"
Unidad: "dosis"
MinQty: 10 (10 dosis por caja)

Precio del Lote (caja completa): $1,000.00
Cálculo: $1,000.00 ÷ 10 = $100.00 por dosis

PrecioUnitario retornado: $100.00
```

### **Otro Ejemplo**

```
Item: "Sutura Absorbible"
Unidad: "sobres"
MinQty: 5 (5 sobres por paquete)

Precio del Lote (paquete completo): $400.00
Cálculo: $400.00 ÷ 5 = $80.00 por sobre

PrecioUnitario retornado: $80.00
```

```csharp
public class InventarioItemDTO
{
    public Guid ItemId { get; set; }
    public string? Nombre { get; set; }
    public decimal MinQty { get; set; }          // Unidades por presentación
    public string? Unidad { get; set; }
    public decimal TotalDisponible { get; set; }
    public decimal? PrecioUnitario { get; set; } // Precio por unidad individual ?

}
```

#### **LoteInventarioDTO.cs**
```csharp
public class LoteInventarioDTO
{
    public Guid LoteId { get; set; }
    public string? Lote { get; set; }
    public DateTime? ExpDate { get; set; }
    public decimal QtyDisponible { get; set; }
    public decimal PrecioUnitario { get; set; } // Precio por unidad individual ?
}
```

### 2. Servicio Actualizado

**ItemInventarioService.cs**

```csharp
// 1. Obtener precio del lote desde DetalleCompra
var detalleCompra = await _context.DetallesCompras
    .Where(dc => dc.ItemId == item.Id && dc.Lote == loteMasProximo.Lote)
    .OrderByDescending(dc => dc.Compra.FechaCompra)
    .FirstOrDefaultAsync();

if (detalleCompra != null)
{
    // Precio del lote completo (presentación)
    precioUnitario = detalleCompra.PrecioUnitario;
    
    // 2. Calcular precio por unidad individual
    // PrecioUnitario del lote / MinQty (unidades por presentación)
    if (item.MinQty > 0)
    {
        precioUnitarioPorUnidad = precioUnitario / item.MinQty;
    }
    else
    {
        // Si MinQty es 0, usar el precio del lote directamente
        precioUnitarioPorUnidad = precioUnitario;
    }
}
```

### Caso 1: MinQty = 0
```csharp
if (item.MinQty > 0)
{
    precioUnitarioPorUnidad = precioUnitario / item.MinQty;
}
else
{
    // Si MinQty es 0, usar el precio del lote directamente
    precioUnitarioPorUnidad = precioUnitario;
}
```

### Caso 2: MinQty = 1
```
Precio del lote: $50.00
MinQty: 1

Cálculo: $50.00 ÷ 1 = $50.00
(El precio unitario es igual al precio del lote)
```

### Caso 3: Decimales
```
Precio del lote: $100.00
MinQty: 3

Cálculo: $100.00 ÷ 3 = $33.33 (redondeado a 2 decimales)
```

## ?? Ventajas de esta Implementación

### ? **Precio Real por Unidad**
El veterinario ve el costo exacto por dosis/ml/sobre, no por presentación completa.

### ? **Cálculos Precisos en Tickets**
```
Ticket: 5 dosis × $100/dosis = $500
(No: 0.5 cajas × $1,000/caja = $500)
```

### ? **Consistencia con Stock**
El stock se maneja en unidades individuales (ml, dosis, sobres), ahora el precio también.

### ? **Sin Cambios en BD**
Usa los datos existentes (`DetalleCompra.PrecioUnitario` y `Item.MinQty`).

## ? Resumen

| Aspecto | Descripción |
|---------|-------------|
| **Fórmula** | `Precio del Lote ÷ MinQty` |
| **Representa** | Precio por unidad individual (ml, dosis, sobre) |
| **Ventaja** | Cálculos precisos y coherentes con el stock |
| **Base de datos** | Sin cambios |
| **Lógica FIFO** | Mantiene el precio del lote que se usará primero |

**El precio unitario ahora representa el costo real por unidad individual del insumo, facilitando la creación de tickets y cálculos de costos.**
